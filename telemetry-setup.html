SRPH AI Coach — getting your telemetry

how to produce the .ld files this app runs on (Assetto Corsa Competizione)

What this app needs

One MoTeC .ld file per driving session. That single file contains everything: lap times, speed, throttle / brake / steering, gear and your position on track — the app decodes it entirely in your browser (nothing is uploaded anywhere).

You do not need to select channels or configure layouts. ACC’s standard full MoTeC log already contains every channel this tool reads.

1 — Make sure recording is on in ACC

  1. In the main menu open Options → Telemetry and confirm that MoTeC data logging is enabled. (If you have never touched it, it is usually on by default.)
  2. Get into a session (practice / qualifying / race) and press M to open the live MoTeC dashboard. If speed, pedal and steering values are moving there, your car is logging.
  3. Drive normally and leave the session — ACC writes the .ld file when the session ends.
Quick check after a session: open the telemetry folder (below) and confirm a new file appeared, a few MB in size. If you completed laps but no file shows up, re-check the Options → Telemetry setting and try the next session.

2 — Where your files are saved

Windows:

Documents\Assetto Corsa Competizione\telemetry\<car>\<track>\

Linux / macOS:

~/Documents/Assetto Corsa Competizione/telemetry/<car>/<track>/

Filenames are generated by ACC, e.g.:

17102026-175924-Leo OdulioPRO-typer_fl5_spoon_st-rt_suzuka-suzukagp.ld

PartMeaning
17102026-175924date (DDMMYYYY) and time (HHMMSS)
Leo OdulioPROdriver name + car
typer_fl5_spoon_stcar preset
rt_suzuka-suzukagptrack (folder – layout)

You can rename or move files freely — the app reads what is inside, not the name. One file = one session/stint.

3 — Tips for getting useful data

  • Log full sessions, not fragments. The app discards your first two laps as settling (engine, tires, strategy warming up), so a session needs at least ~4–5 completed laps to yield anything usable. More is better — consistency analysis wants a proper sample.
  • Keep conditions comparable when comparing. Same track layout, same car, similar fuel/traffic state. Cross-session comparison works best between your own sessions on the same circuit.
  • Aim for clean laps. The smoother and more repeatable your inputs, the more of a time gap the analysis can attribute to specific corners instead of “general messiness”.
  • No special settings needed for depth. Suspension travel, tire temperature / pressure / slip angle and brake bias are logged in the same standard file — they power the setup-side (Phase 2) features without any extra configuration.

4 — Then

← Back to the app. Drop your .ld file onto the upload area, pick two laps to compare, and read the per-corner breakdown. For a baseline of “your normal”, build one from any of your own sessions in-app.
